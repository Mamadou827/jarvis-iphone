JARVIS — prototype d'interface web mobile

Contenu :
- index.html : interface
- style.css : style bleu premium adaptatif
- app.js : interactions de maquette et tentative de dictée vocale du navigateur
- manifest.json : métadonnées pour une future installation PWA

IMPORTANT :
Cette première version est seulement l'interface. Elle n'est pas encore connectée à une IA,
à une mémoire en ligne, ni à un serveur. Les messages restent dans la page et ne sont pas
synchronisés. N'y saisis aucune information privée pour le moment.

Étape suivante :
héberger l'interface, puis construire un backend sécurisé avec authentification et une
solution d'IA compatible avec le budget et le pays d'utilisation. Pour l'ajouter à l'écran
d'accueil de l'iPhone, le site devra être publié en HTTPS.
